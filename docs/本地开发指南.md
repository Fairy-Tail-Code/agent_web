# 本地开发指南

## 快速开始

### 1. 启动后端服务（开发模式）

```bash
cd agent_web
docker-compose -f docker-compose.dev.yaml up -d
```

访问：`http://localhost:8080`

### 2. 前端独立开发（可选）

如果你需要前端热重载和独立调试：

```bash
cd agent-web-fronted
npm install
npm run dev
```

访问：`http://localhost:5173`

---

## 开发模式特性

### 后端
- ✅ 热重载（修改代码自动重启）
- ✅ 代码挂载（容器内修改会同步到本地）
- ✅ HTTP 模式（无需 SSL 证书）
- ✅ 更宽松的速率限制（100 req/s）

### 前端
- ✅ 热重载（Vite HMR）
- ✅ 本地代理配置（vite.config.ts）

## 常用命令

```bash
# 启动开发环境
docker-compose -f docker-compose.dev.yaml up -d

# 查看日志
docker-compose -f docker-compose.dev.yaml logs -f

# 查看特定服务日志
docker-compose -f docker-compose.dev.yaml logs -f app
docker-compose -f docker-compose.dev.yaml logs -f gateway

# 停止服务
docker-compose -f docker-compose.dev.yaml down

# 重建镜像
docker-compose -f docker-compose.dev.yaml up -d --build

# 清理所有数据（谨慎使用）
docker-compose -f docker-compose.dev.yaml down -v
```

## 目录挂载（开发模式）

以下目录会挂载到容器，修改代码后立即生效：

- `./api` → `/app/api`
- `./agent` → `/app/agent`
- `./config` → `/app/config`
- `./auth` → `/app/auth`
- `./knowledge` → `/app/knowledge`
- `./tools` → `/app/tools`

## 前后端联调

### 方式 1：完整 Docker 环境（推荐）
```bash
cd agent_web
docker-compose -f docker-compose.dev.yaml up -d
```
访问 `http://localhost:8080`

### 方式 2：后端 Docker + 前端本地
```bash
# 启动后端
cd agent_web
docker-compose -f docker-compose.dev.yaml up -d

# 启动前端（新终端）
cd ../agent-web-fronted-2
npm run dev
```
访问 `http://localhost:5173`，通过 Vite 代理访问后端

## 故障排查

### 端口被占用
```bash
# Windows
netstat -ano | findstr :8080

# Linux/Mac
lsof -i :8080
```

### 容器无法启动
```bash
# 查看详细日志
docker-compose -f docker-compose.dev.yaml logs

# 重启服务
docker-compose -f docker-compose.dev.yaml restart
```

### 数据库连接失败
检查 `.env` 中的数据库配置是否正确
